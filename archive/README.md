that this workflow was consolidated from. Their content has been split into the
`dev-flow` skill:

  tool maps, defaults, known gaps) → `../skills/dev-flow/references/<stack>.md`.
- **Copyable configuration and code** → `../skills/dev-flow/templates/<stack>-quality/`.

They are kept here only as reference for the original wording; do not treat them
